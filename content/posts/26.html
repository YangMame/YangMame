Tor

假设你已经有了个代理且代理地址和端口为：127.0.0.1:8118

首先你需要一个tor后端

Gentoo用户：

emerge tor
rc-update add tor default

Arch用户：

pacman -S tor
systemd enable tor

其它发行版类似

然后修改tor的配置：

vim /etc/tor/torrc

修改为如下：

User tor

PIDFile /var/run/tor/tor.pid
Log notice syslog

DataDirectory   /var/lib/tor/data

ControlPort 9051
CookieAuthentication 1

CookieAuthFile /var/lib/tor/auth/control_auth_cookie
CookieAuthFileGroupReadable 1

HTTPSProxy 127.0.0.1:8118

rc-service tor start或systemd start tor启动tor

然后你就需要安装torbrowser了

官网（需番茄）有中文版 解压就能用 但是俺懒得自己手动更新所以选择通过包管理安装

最后在tor浏览器的代理设置里面设置socks5代理为127.0.0.1端口为9050然后测试下是否能上谷歌

ZeroNet

一般来说配合tor使用才能保证安全性

Gentoo用户：

emerge -a layman
layman -a raiagent
USE="tor" emerge zeronet

然后把net-vpn/zeronet tor加到package.use

安装完之后会有提示

这里简单说下：

rc-service tor stop
usermod --append --groups=tor zeronet
mkdir --mode=750 /var/lib/tor/auth
chown -R tor: /var/lib/tor/auth
rc-update zeronet default
rc-service zeronet restart

在浏览器打开http://127.0.0.1:43110即可访问了

进入之后 在ZeroMe注册属于你的id之后 最好备份下/var/lib/zeronet/users.json

ZeroNet不会帮你找回帐号的！需要自己妥善保存

I2P

Gentoo用户：

emerge -av i2p
rc-update add i2p default
rc-service i2p start

Arch用户:

pacman -S i2p
systemctl enable i2p #我也不知道它有没有systemd服务
systemctl start i2p

然后通过浏览器访问： http://localhost:7657/home 进入控制台
